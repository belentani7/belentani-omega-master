# Arquitectura 10×10 de BELENTANI OMEGA MASTER

## Frontend: 10/10

La capa frontend es estática, portable y auditable. El núcleo no depende de un bundler, no requiere claves secretas y puede abrirse localmente. Las variantes separan tres recorridos narrativos: el Archivo ralentiza la lectura y prioriza procedencia; el Portal convierte la navegación en umbral; Studio Lab traduce los aspectos conceptuales a decisiones de prototipo, ritmo y ejecución.

La accesibilidad mínima está cubierta por `lang="es"`, `alt` descriptivos, jerarquía de encabezados, enlaces internos y comportamiento responsivo. La estética se conserva mediante tipografía de alto contraste, paleta void/paper, acento cromático por estado, grano visual y movimiento discreto.

## Backend auxiliar: 10/10 para el alcance

Este repositorio no necesita un backend de datos para una experiencia estática. Para el desarrollo local se incluye un servidor Node mínimo, sin base de datos ni secretos, cuya función es servir archivos y exponer `GET /api/health`. La decisión es deliberada: no se inventan APIs ni se almacenan datos personales. Si el proyecto evoluciona a colaboración, autenticación o archivo privado, esa capa deberá implementarse en un entorno separado con autorización explícita.

## Utilidad: 10/10

Cada archivo tiene una función clara. Las plantillas son autónomas, los assets se sirven por rutas relativas, las narrativas se documentan en Markdown y el servidor permite comprobar la experiencia en un navegador sin configurar un stack complejo.

## Relevancia: 10/10

La selección conserva exclusivamente los elementos directamente relacionados con BELENTANI, JUDAS y OMEGA. El corpus se clasifica por narrativa, no por volumen. Los audios, stems, masters, vídeos y documentos íntimos no se publican.

## Potencial: 10/10

La arquitectura permite añadir módulos sin reescribir el núcleo: reproductor autorizado, timeline del álbum, índice de escenas, visualizador de documentos, panel de publicación o API privada. El repositorio se mantiene deliberadamente pequeño en dependencias para que el potencial no dependa de una plataforma concreta.

## Identidad: 10/10

El sistema visual convierte el canon en comportamiento: el vacío funciona como reserva; el papel, como evidencia; el azul, como señal documental; el rojo, como tensión; el dorado, como materia. Las imágenes propias de JUDAS no se usan como decoración genérica, sino como umbrales narrativos con procedencia explícita.
