## 2. Planes Narrativos por Grupo

### Grupo 1: Canon y Legajo (La Memoria Documental)
- **Plan Narrativo:** Estructurar el corpus en tres capas inmutables: **Origen** (el punto de partida identitario), **Quiebre/Límite** (la fricción con el entorno y la toma de conciencia) y **Transmutación** (la obra como soberanía).
- **Regla de Privacidad:** Se excluyen por completo transcripciones de chat, nombres de terceros, datos económicos o material íntimo. La narrativa opera únicamente sobre principios conceptuales universales y directrices de dirección.

### Grupo 2: Media y Visual (La Estética JUDAS)
- **Plan Narrativo:** Organizar los fotogramas, portadas y hojas de contacto recuperadas (`judas-cathedral-threshold.webp`, `judas-signal-ship.webp`, `judas-desert-armour.webp`) bajo el tratamiento de claroscuro barroco e IMAX.
- **Función en el Sistema:** Cada imagen actúa como umbral visual y transición de estado, conectando la música conceptual con la arquitectura web.

### Grupo 3: Code y Core (El Sistema Operativo OMEGA)
- **Plan Narrativo:** Desarrollar una interfaz de altísima densidad técnica que fusione la estética de *Dogstudio* y *Dragonfly*. El código se despliega en dos niveles: un núcleo masivo de 30,000 líneas para archivo total y tres variantes modulares de 3,000 líneas optimizadas para Archivo, Portal y Studio Lab.
