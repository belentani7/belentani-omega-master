# BELENTANI OMEGA MASTER

> Repositorio maestro privado para la experiencia digital, el archivo visual y la narrativa de JUDAS de Pedro Belentani.

Este proyecto consolida únicamente los materiales que superaron la auditoría de relevancia, utilidad, potencial e identidad. La experiencia se divide en un núcleo principal, tres variantes HTML de alta densidad y un pequeño servidor auxiliar para servir los assets de forma segura durante el desarrollo local.

## Estructura narrativa

| Grupo | Relato | Implementación |
|---|---|---|
| Canon | Origen, límite y transmutación. | `docs/BIBLIA_CONCEPTUAL.md` y `docs/SUPREME_AUDIT_MASTER.md` |
| Media | Umbral, señal, cuerpo y materia. | `assets/judas/` y las tres variantes 3K |
| Code | Archivo vivo, portal y laboratorio. | `index.html`, `belentani_omega_30k.html` y variantes |

## Entradas principales

`index.html` funciona como experiencia principal. `belentani_omega_30k.html` es el archivo conceptual masivo con más de 30,000 líneas. `belentani_archive_3k.html`, `belentani_portal_3k.html` y `belentani_studio_3k.html` son tres lecturas especializadas de más de 3,000 líneas cada una.

Los documentos de `docs/` contienen la auditoría, la matriz de assets, la Biblia conceptual, el tratamiento del álbum JUDAS y la arquitectura de aplicación de los aspectos conceptuales. Los assets visuales publicados son locales; no se incluyen audios, stems, masters, vídeos ni documentos íntimos del Drive.

## Ejecución local

Para una revisión rápida se puede abrir cualquier HTML directamente en un navegador moderno. Para servir las rutas de assets de forma consistente, se recomienda usar Node.js:

```bash
npm run dev
```

Después, abrir `http://localhost:4173/`.

## Auditoría de publicación

El repositorio no contiene transcripciones privadas, nombres de terceros, conversaciones, datos económicos ni material íntimo. La implementación masiva utiliza una síntesis conceptual pública y los recursos visuales seleccionados por su relevancia narrativa. La clasificación y los criterios de exclusión están documentados en `docs/DRIVE_ASSET_CATALOG.md`.
